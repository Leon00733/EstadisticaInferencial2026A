# Gym Members Exercise Dataset

## Description

This dataset provides a detailed overview of **gym members' exercise routines, physical attributes, and fitness metrics**. It contains **973 samples** of gym data, including key performance indicators such as heart rate, calories burned, and workout duration.

Each entry also includes demographic data and experience levels, allowing for comprehensive analysis of **fitness patterns, athlete progression, and health trends**.

## Key Features

| Variable | Description |
|---|---|
| **Age** | Age of the gym member. |
| **Gender** | Gender of the gym member (`Male` or `Female`). |
| **Weight (kg)** | Member's weight in kilograms. |
| **Height (m)** | Member's height in meters. |
| **Max_BPM** | Maximum heart rate, measured in beats per minute, during workout sessions. |
| **Avg_BPM** | Average heart rate during workout sessions. |
| **Resting_BPM** | Heart rate at rest before the workout. |
| **Session_Duration (hours)** | Duration of each workout session in hours. |
| **Calories_Burned** | Total calories burned during each session. |
| **Workout_Type** | Type of workout performed, such as `Cardio`, `Strength`, `Yoga`, or `HIIT`. |
| **Fat_Percentage** | Body fat percentage of the member. |
| **Water_Intake (liters)** | Daily water intake during workouts. |
| **Workout_Frequency (days/week)** | Number of workout sessions performed per week. |
| **Experience_Level** | Experience level of the member, ranging from beginner (`1`) to expert (`3`). |
| **BMI** | Body Mass Index, calculated using height and weight. |

## Dataset Size

- **Number of samples:** 973
- **Number of variables:** 15
- **Data types:** Numerical and categorical
- **Main areas:** Demographics, physiological metrics, workout characteristics, and fitness indicators

## Potential Applications

This dataset can be useful for:

- Analyzing **exercise and fitness habits**.
- Studying the relationship between **demographic and physiological variables**.
- Identifying factors associated with **calories burned**.
- Comparing different **workout types**.
- Examining the relationship between **BMI, body fat, and exercise frequency**.
- Analyzing differences according to **experience level**.
- Developing predictive models related to **fitness performance and progression**.
